command key: All device templates (ZIP) Combined VIU Combined VO
How to connect in Loxone Config
  1. Set the Miniserver IP and save. Select the channels you need below — the selection is saved immediately.
  2. Templates are generated per device: the Loxone block is named after the device (the "Name in Loxone" field), files are VIU_Name.xml and VO_Name.xml. Download them with the VIU / VO buttons on a device, or all at once as a ZIP.
  3. Put the files into Documents\Loxone\Loxone Config\Templates\VirtualIn (VIU_) and …\VirtualOut (VO_), or import them: Peripherals → Virtual Inputs → Import template (and the same for Virtual Outputs).
  4. Drag the inputs/outputs you need onto the program page and save to the Miniserver.
  5. Values arrive over UDP right when they change; every "Full resend" interval the bridge repeats all of them, so Loxone picks them up after a reboot.
  6. Buttons. Every input with a counter (Input N + Input N counter) gets "single", "double", "triple" and "long" channels — a 1→0 pulse. The press count comes from the module's hardware counter, so short presses are not lost even on a slow bus. Holding for dimming and blinds is the regular Input N channel. A single press arrives after "Wait for next press" following the release.
  7. RGB: the Loxone output (BBBGGGRRR, %) is converted to WB R;G;B automatically. Dimmers and setpoints are analog outputs <v>.
  8. After changing the channel selection, import the template again — Loxone adds the missing commands to an existing block with the same name if you import over it.

Loxone commands arrive at http://WB:port/set/key/device/channel/value. Without the correct key, and for unselected channels, commands are rejected.
